🛡️ CyberShield Detection Rules & Thresholds

CyberShield applies automated pattern recognition and anomaly detection algorithms across server access logs to uncover unauthorized intrusions:

  • Brute Force Detection: Flags IP addresses triggering ≥ 5 LOGIN_FAILED events.
  • Suspicious Request Scanning: Detects repetitive UNAUTHORIZED_ACCESS, FORBIDDEN_REQUEST, or HTTP 403/404 forbidden responses (threshold ≥ 3).
  • Risk Assessment Engine:
    • HIGH RISK: Occurrence count ≥ 5
    • MEDIUM RISK: Occurrence count 3 – 4
    • LOW RISK: Occurrence count < 3
